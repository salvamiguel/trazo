# Icon packs

Generated by `pnpm --filter @trazo/core icons` (`scripts/icon-packs.ts`). Do not edit by hand.

- `aws.json`: AWS Architecture Icons, © Amazon Web Services, from the `aws-icons` npm package.
  AWS allows customers and partners to use them to create architecture diagrams
  (https://aws.amazon.com/architecture/icons/).
- `azure.json`: Azure Architecture Icons V24, © Microsoft, from `@squinch/pack-azure`.
  Microsoft permits their use in architectural diagrams, training materials and documentation
  (https://learn.microsoft.com/en-us/azure/architecture/icons/).
- `core.json`: subset of the above plus Iconify `logos` (CC0) and `tabler` (MIT) icons that is always loaded.
- `index.json`: names, titles and categories of every pack, for search.
- `k8s.json`: Kubernetes icons, © The Kubernetes Authors, CC BY 4.0
  (https://github.com/kubernetes/community/tree/master/icons), via `@iconify-json/k8s`.
- `cncf.json`: logos of CNCF projects from https://github.com/cncf/artwork (CC BY 4.0), plus
  External Secrets, Karpenter (from their repositories) and Traefik (via `@iconify-json/devicon`, MIT).
  The logos are trademarks of their projects; Trazo uses them to identify those projects in diagrams.
